Housing Price Prediction 🏡
📌 Project Overview
You will be provided with a dataset of housing features and prices. The goal of this project is to build a regression model that can predict house prices based on the given features.
For this task, you may use R, Python, or any tool of your choice. Similarly, you are free to select the regression algorithm that best fits the problem (e.g., Linear Regression, Random Forest, Gradient Boosting, etc.).
The project is evaluated based on two key deliverables:
1. 	Feature Importance (50%)
• 	Identify and explain the importance of each feature in the model.
• 	Provide insights into which features most strongly influence housing prices.
2. 	House Price Predictions (50%)
• 	Predict the house prices in the provided test set.
• 	Present the estimated values clearly for evaluation.
